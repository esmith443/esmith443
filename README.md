## Projects

### Windows &amp; infrastructure tooling

| Repo | What it does |
|---|---|
| [**Veeam-Toolkit**](https://github.com/esmith443/Veeam-Toolkit) | Single-exe service manager + diagnostic collector for Veeam B&amp;R. Dependency-ordered service control with a running-job guard. |
| [**Mail-Migrate**](https://github.com/esmith443/Mail-Migrate) | Windows console for migrating Exchange Server 2019 to mailcow: inventory, transform, settings import, mailbox sync via imapsync. |
| [**PIA-PORT-CHANGER**](https://github.com/esmith443/PIA-PORT-CHANGER) | Detects when PIA rotates your forwarded port and updates qBittorrent so seeding does not silently break. |

### Rust server plugins &amp; dashboards

| Repo | What it does |
|---|---|
| [**JSExtendedStats**](https://github.com/esmith443/JSExtendedStats) | Leaderboard and stats platform: Node.js web app + admin panel, MySQL schema, and an Oxide plugin tracking 40+ stats. |
| [**TeamRotation**](https://github.com/esmith443/TeamRotation) | Lets team leaders rotate offline players out, stripping auth from TCs, locks and turrets and blocking re-auth until wipe. |
| [**AuthLimit**](https://github.com/esmith443/AuthLimit) | Caps how many players can be authorized on a TC, code lock or auto turret, with optional Discord webhook alerts. |

### Discord bots

| Repo | What it does |
|---|---|
| [**Rust-Player-Tracker**](https://github.com/esmith443/Rust-Player-Tracker) | Tracks players via the BattleMetrics API and posts real-time online/offline notifications from a persistent watchlist. |
| [**Streamer-GOLIVE-Bot**](https://github.com/esmith443/Streamer-GOLIVE-Bot) | Monitors YouTube, Twitch, TikTok and Kick and notifies when a streamer goes live. |

### Browser &amp; networking

| Repo | What it does |
|---|---|
| [**Full-Page-Scraper**](https://github.com/esmith443/Full-Page-Scraper) | Chrome extension that saves a page's full assets locally and generates a `context.md` summary for an AI assistant. |
| [**Unifi-Netflix-Bypass**](https://github.com/esmith443/Unifi-Netflix-Bypass) | UniFi policy-based routing so a Netflix account works across locations without paying for an extra Home Location. |
| [**Verizon-ONT-Bypass**](https://github.com/esmith443/Verizon-ONT-Bypass) | Replacing the Verizon FiOS ONT with an Iszo XPON ONU so a UDM Pro terminates GPON directly. |
| [**RustPrivateID**](https://github.com/esmith443/RustPrivateID) | If you know, you know. |
